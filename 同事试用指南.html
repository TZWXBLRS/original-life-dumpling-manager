# 方案A：ngrok（推荐，最稳。官网 ngrok.com 免费注册拿 token）
ngrok http 3000

# 方案B：localtunnel（npm 自带一条命令，免注册）
npx localtunnel --port 3000 --subdomain dumpling-sushenghuo

# 方案C：Cloudflare Quick Tunnel（下载一次cloudflared，免注册）
# macOS:  brew install cloudflared
# Windows/Linux:  https://developers.cloudflare.com/cloudflare-one/connections/connect-networks/downloads/
cloudflared tunnel --url http://localhost:3000
✅ 方案 B 最快：cd /workspace/original-life-dumpling-manager 项目目录里直接跑那条 npx localtunnel 即可。

🧭 三、推荐试用流程（按顺序玩）

#谁来玩干啥进哪个页面重点体验 & 吐槽点
1顾客 注册 + 逛饺子口味 /products 8 种口味、特色 vs 经典标签、只数说明、库存显示对不对
2顾客 加购物车 → 结算 /cart → /checkout ✅ 定价算法（经典4盒100 / 特色3盒100 / 混拼加差价 / 泡沫箱5元）✅ 自取时间 / 快递省份时效（≤1晚安全，>1晚警告，海南新疆不支持）✅ 冷冻8小时校验和「顾客自行承担风险」勾选项
3顾客 提交订单 → 查看订单详情 → 点「取消订单」 /orders/[id] 待支付的订单，顾客能自己取消；已支付的取消会提示联系门店（并返还库存）
4管理员 管理员登录 → 找那笔订单 → 标记支付 /orders/[id] 状态时间线：支付、备餐、备好、发货、完成 — 每个节点都记录时间戳
5后厨 后厨登录 → 生产看板 /admin/production ✅ 今日总盒数、自取/快递各几单 ✅ 按口味备货（三鲜要备几盒、黑松露还差几盒）✅ 三色进度条：待备 / 备餐中 / 备好 ✅ 点订单直接跳详情改状态
6后厨 库存入库（模拟冷冻饺子入库） /admin/inventory 入库时勾选「刷新冷冻时间」，入库后 8 小时内 快递订单会提示「需要前台冷冻确认」才能发货
7管理员 发货（快递单） /orders/[id] 或 /admin/orders/[id]/ship ✅ 未满8小时冷冻的单，必须勾选「我已确认冷冻情况」才能发货 ✅ 已满的可直接发货
8管理员 新增后厨/管理员账号 /admin/users 新增员工、重置密码、禁用启用、切换角色（不能把自己降权/禁用）
9管理员 改门店信息 / 营业参数 /admin/settings 门店名、电话、自取地址、营业时间(JSON)、每日限购盒数、泡沫箱价格和容量

🙏 五、反馈建议重点收集（老板你可以直接复制发群）

麻烦大家重点看看这几块，拍截图或直接说想法都可以：

  • 价格对不对：有没有出现经典/特色/混拼算错钱的情况？
  • 快递时效准不准：你所在省份，系统显示几天到？和实际京东快递差多少？
  • 冷冻8小时逻辑：前台是否能清晰看到「这批发货是否要先确认冷冻」？
  • 后厨看板好不好用：口味汇总够不够直观？能不能一眼看出今天还要做多少？
  • 页面颜值 & 手机适配：用手机打开会不会歪？字会不会太小？
  • 操作流程：哪些步骤你觉得多此一举？哪些还可以更傻瓜？
  • 功能遗漏：还有什么必须要有但没做的？（比如打印小票、对接微信付款、京东快递面单……）
